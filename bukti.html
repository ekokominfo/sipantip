Yang benar-benar teramati

  1. Peta Leaflet. DOM memuat Leaflet 1.9.4, markercluster 1.5.3, dan leaflet-velocity 1.7.0.
  2. Tiga feed hotspot. Permintaan ke hotspot_high2.json, hotspot_medium2.json, dan hotspot_low2.json semuanya menerima HTTP 200. Host: appscript.palangkaraya.go.id/hotspot/api/.
  3. Kualitas udara model. Permintaan Open-Meteo Air Quality membawa parameter hourly=us_aqi,pm2_5,pm10,... dan koordinat Palangka Raya. Respons HTTP 200.
  4. Data lokal tambahan. Browser meminta pm25_pky.json, visibility_pky.json, puskesmas.json, dan ispa.json. Semuanya HTTP 200. Ini tidak membuktikan data tersebut berlaku untuk Pulang Pisau.
  5. Arsip dan berita. Teramati permintaan ringkasan harian JSON, arsip AQI JSONL, serta WordPress REST API BPBD dan Kominfo.

Temuan dari kode halaman

DOM yang ditangkap memuat JavaScript yang membaca data.features, koordinat GeoJSON, serta properti kabupaten, kecamatan, desa, satelit, date_hotspot, dan confidence.

Kode loadHotspots() menggunakan Promise.allSettled untuk tiga feed. normConf() memetakan nilai angka ≥80 menjadi High, ≥30 menjadi Medium, sisanya Low; teks nominal menjadi Medium.

Kode menjadwalkan loadAll() setiap 10 menit saat tab terlihat. Ini adalah bukti konfigurasi kode, bukan bukti pengamatan selama 10 menit. Kode kompas memiliki interval 15 menit.

Adaptasi untuk Pulang Pisau

Implementasi baru memakai feed hotspot yang sama dan menyaring atribut kabupaten ke Pulang Pisau. Peta dan hitungan mengikuti hasil filter kecamatan, tanggal, kepercayaan, serta pencarian.

Model kualitas udara dan angin memakai titik acuan sekitar ibu kota kabupaten (−2,75°, 114,25°). Ini bukan sensor lokal atau rata-rata kabupaten. Data kesehatan dan sensor Palangka Raya tidak digunakan. Wilayah administratif tidak digambar sebelum tersedia geometri resmi.

Batas bukti

HTTP 200 membuktikan respons berhasil dalam sesi observasi, bukan akurasi data atau jaminan ketersediaan layanan. Beberapa badan respons tidak tersimpan karena batas ukuran 65.536 byte; tidak ada klaim bahwa seluruh payload dianalisis. Pengamatan tidak mengungkap kode server, proses pengambilan data satelit, jadwal backend, atau akses internal.
